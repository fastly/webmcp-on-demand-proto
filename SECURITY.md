## Report a security issue

The project team welcomes security reports and is committed to providing prompt attention to security issues. Security issues should be reported privately via [Fastly’s security issue reporting process](https://www.fastly.com/security/report-security-issue).

## Security advisories

Remediation of security vulnerabilities is prioritized by the project team. The project team endeavors to coordinate remediation with third-party stakeholders, and is committed to transparency in the disclosure process. The team announces security issues via [this repository's GitHub releases and security advisories](https://github.com/fastly/webmcp-on-demand-proto/security/advisories) on a best-effort basis.

## Supported versions

This repository is a proof of concept and is not supported for production use. There are no supported release lines; security fixes land on `main` only.

Note that communications related to security issues in Fastly-maintained OSS as described here are distinct from [Fastly Security Advisories](https://www.fastly.com/security-advisories).
